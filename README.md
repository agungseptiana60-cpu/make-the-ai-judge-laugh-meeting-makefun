One line about office life: the meeting to save time ran two hours over, so we booked another meeting to investigate why the meeting to save time took so long. The program in `main.ts` writes that single line (131 characters) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
